Creating and Publishing Jupyter Notebooks#

Tutorials for BIOL 4160/8166 — Bioinformatics for Biologists

The tutorials walk you through everything you need to produce a Jupyter Notebook that meets the course project requirements, from opening JupyterLab for the first time to exporting a finished notebook you can hand in with your progress report or final paper.

It is organized as a small set of self-contained chapters. You can read them in order the first time, then come back to any single chapter as a reference later in the semester.

What you will be able to do

  • Launch JupyterLab on the Holland Computing Center (HCC) with no local installation

  • Create, organize, and run a notebook

  • Write a notebook that is reproducible, well-documented, and easy to grade

  • Export your finished notebook for submission

  • Publish a set of notebooks as a Jupyter Book like this one

Course infrastructure reminder

All course computing happens through the HCC Open OnDemand portal at swan-ood.unl.edu, under the class allocation group glu4class. You do not need to install Python, Jupyter, or any bioinformatics tools on your own computer.
