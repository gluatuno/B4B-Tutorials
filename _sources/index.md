# Creating and Publishing Jupyter Notebooks

**Training materials for BIOL 4160/8166 — Bioinformatics for Biologists**

This short course walks you through everything you need to produce a
Jupyter Notebook that meets the course project requirements, from opening
JupyterLab for the first time to exporting a finished notebook you can
hand in with your progress report or final paper.

It is organized as a small set of self-contained chapters. You can read
them in order the first time, then come back to any single chapter as a
reference later in the semester.

```{admonition} What you will be able to do
:class: tip
- Launch JupyterLab on the Holland Computing Center (HCC) with no local
  installation
- Create, organize, and run a notebook
- Write a notebook that is reproducible, well-documented, and easy to grade
- Export your finished notebook for submission
- (Optional, for TAs/instructors) Publish a set of notebooks as a Jupyter
  Book like this one
```
